# Шинэ гэрийн найр — Цахим урилга

Монгол уламжлалт хэв маяг, орчин үеийн хөдөлгөөнт анимаци бүхий бие даасан цахим урилгын вэб аппликейшн.

## 🌟 Онцлогууд
- **Хаалга нээх анимаци (Focus Scene Gate):** Уламжлалт Түмэн наст хээний виньетка, лугших цагирагтай товчлуур дээр дарахад хаалга нээгдэнэ.
- **HTML5 Canvas Салют:** Хаалга нээгдэх үед болон үргэлжлэн буух бодит пуужин, оч бүхий салютын хөдөлгөөнт систем.
- **Хуанли ба Бодит цагийн тоолуур:** 2026 оны 10-р сарын 13-ны өдрийг тодруулсан хуанли, үйл ажиллагаа эхлэх хүртэлх өдөр, цаг, минут, секундын тоолуур.
- **Зочдын цагийн хуваарь:** Хамаатан садан, Хамт олон, Ангийн найзууд хүлээн авах нарийвчилсан хуваарь.
- **Байршил ба Газрын зураг:** Сайншанд хотын 223-р байрны яг нарийн координат (`44.88799, 110.1286`) дээрх OpenStreetMap зураглал болон Google Maps чиглэл заах товч.
- **Холбоо барих:** 9601 1047 дугаар луу шууд залгах товч.
- **Арын фон хөгжим:** YouTube тоглуулагч удирдлагатай.

# Сангуудыг суулгах

# Хөгжүүлэлтийн горимд ажиллуулах
